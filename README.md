# بوت مكتبة الصوتيات العربية عبر واتساب (الإصدار 2.0)

مشروع احترافي متكامل لبناء وتطوير بوت واتساب يعمل كمكتبة صوتيات رقمية شاملة. يسمح البوت للمستخدمين بالبحث عن الصوتيات وتنزيلها واقتراح إضافة صوتيات جديدة، بينما يمنح المسؤولين (الأدمن) لوحة تحكم كاملة من داخل واتساب لإدارة المكتبة ومراجعة الطلبات ورفع الملفات مباشرة إلى مستودع Hugging Face Datasets.

---

## 🚀 التقنيات المستخدمة

- **Node.js** (إصدار 20 فما فوق).
- **@whiskeysockets/baileys** للاتصال بحساب واتساب عبر الويب بشكل مؤتمت.
- **Express.js** كخادم ويب خفيف لعرض رمز QR وكود الربط وفحص حالة البوت.
- **SQLite** كقاعدة بيانات محلية لتخزين سجلات الصوتيات والمستخدمين والتحميلات.
- **Hugging Face Datasets** لتخزين ملفات الصوتيات والفيديوهات وتوفير روابط تحميل مباشرة وسريعة.
- **Pino / Winston** لتسجيل وحفظ السجلات والأخطاء (Logs).

## ⚙️ الإعداد والتشغيل

### 1. المتغيرات البيئية المطلوبة

انسخ ملف `.env.example` إلى `.env` وعدّل القيم:

```env
PORT=3000
HF_TOKEN=your_huggingface_write_token_here
HF_DATASET=your_username/your_dataset_name
ADMIN_NUMBER=966500000000
BOT_NUMBER=966500000000        # اختياري: لاستخدام كود الربط الرقمي بدل QR
MAX_FILE_SIZE_MB=100
RATE_LIMIT_MS=1000
REQUEST_COOLDOWN_MS=180000
```

### 2. تشغيل البوت

```bash
npm install
npm start
```

### 3. ربط حساب واتساب

افتح الرابط `http://localhost:3000` في المتصفح. ستجد خيارين:
- **كود الربط الرقمي**: أدخله في تطبيق واتساب ← الأجهزة المرتبطة ← ربط برقم الهاتف.
- **رمز QR**: امسحه من تطبيق واتساب مباشرة.

بعد الربط الناجح، تُحفظ الجلسة تلقائياً في Hugging Face وتُستعاد عند كل إعادة تشغيل دون الحاجة لإعادة الربط.

## 🔄 آلية الاستمرارية على Render

يعمل البوت على Render وهي بيئة ذات نظام ملفات مؤقت. للحفاظ على البيانات بين عمليات إعادة التشغيل:

- **قاعدة البيانات** (`database.sqlite`): تُرفع إلى Hugging Face وتُنزَّل عند كل إقلاع.
- **جلسة واتساب** (ملفات `.baileys_auth`): تُرفع بعد كل اتصال ناجح وتُنزَّل عند كل إقلاع.
- **Keep-Alive**: يُرسَل طلب لنفسه كل 14 دقيقة لمنع دخول الخدمة في وضع السكون في الخطة المجانية.

## 💬 قائمة الأوامر المتوفرة

### 👤 أوامر المستخدمين:
- `/start` أو `القائمة`: ترحيب وعرض القائمة الرئيسية.
- `بحث`: يبدأ جلسة البحث عن صوتية (بالعنوان، الملقي، أو الكلمات المفتاحية).
- `تصنيفات`: تصفح الصوتيات المتوفرة مقسمة حسب التصنيفات.
- `جميع`: عرض جميع الصوتيات مع دعم التصفح بالصفحات.
- `جديد`: جلب آخر الصوتيات المضافة للمكتبة.
- `جديد الاسبوع`: صوتيات هذا الأسبوع.
- `مفضلة`: عرض قائمتك المفضلة من الصوتيات.
- `اشتراك`: الاشتراك في أو إلغاء إشعارات الصوتيات الجديدة.
- `اضافة`: تفعيل عملية تقديم صوتية أو فيديو جديد.
- `احصائيات`: عرض إحصائيات عامة للمكتبة.
- `تحميل [UUID]`: تحميل صوتية وإرسالها مباشرة.
- `مفضلة [UUID]`: إضافة صوتية إلى قائمتك المفضلة.
- `حذف_مفضلة [UUID]`: إزالة صوتية من المفضلة.

### 👑 أوامر الأدمن (من رقم المسؤول فقط):
- `طلبات`: عرض طلبات الإضافة المعلقة.
- `قبول [رقم_الطلب]`: الموافقة على الطلب ورفعه لـ Hugging Face.
- `رفض [رقم_الطلب] [السبب]`: رفض الطلب وإشعار المقترح.
- `حذف [UUID أو الاسم]`: حذف صوتية من قاعدة البيانات.
- `تعديل [UUID] العنوان:الجديد | المؤلف:الجديد`: تعديل معلومات صوتية.
- `إحصائيات`: تقرير كامل للأدمن.
- `رسالة جماعية [نص]`: بث رسالة لجميع المشتركين.
- `نسخة احتياطية`: إرسال ملف قاعدة البيانات للأدمن مباشرة.
- `إعادة بناء الفهرس`: تحديث فهرس الذاكرة المؤقتة فوراً.
- `تنظيف`: مسح الملفات المؤقتة التالفة.
- `مزامنة`: فحص الاتصال بـ Hugging Face والتحقق من الصلاحيات.
- `إضافة تصنيف [الاسم]`: إضافة تصنيف جديد.
- `تعديل تصنيف [القديم] [الجديد]`: إعادة تسمية تصنيف.
- `حذف تصنيف [الاسم]`: حذف تصنيف.

## 🔒 الأمان والحماية

1. **التحقق من سلامة الملفات**: فحص نوع الملف الفعلي (ليس فقط الامتداد) قبل القبول.
2. **منع التكرار**: حساب SHA256 للملفات المرفوعة ومطابقتها لمنع التكرار.
3. **محاربة السبام (Rate Limiting)**: حد أدنى للوقت بين الرسائل (افتراضياً 1 ثانية) وفترة انتظار بين طلبات الإضافة (افتراضياً 3 دقائق).
4. **إعادة الاتصال التلقائي**: Exponential backoff عند انقطاع الاتصال (3s → 6s → 12s → ... → 60s).
5. **تنبيهات الأدمن**: إشعار فوري عند الاتصال أو تسجيل الخروج.
